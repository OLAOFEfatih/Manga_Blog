# Manga Blog - Projet de Stage

## 🎯 Description du projet
Manga Blog est un blog interactif dédié aux mangas, permettant de publier et consulter des articles, critiques et actualités sur différents mangas.  
Le projet inclut également une **gestion simple des comptes utilisateurs** pour se connecter, s’inscrire et consulter son profil.

Ce projet a pour objectif de mettre en pratique les compétences front-end (HTML, CSS, JavaScript) et l’utilisation d’un framework front-end (Bootstrap) dans le cadre d’un projet de stage.
